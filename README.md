# Harny

a collection of api calls and flows for anthropics api written with bash scripts

**Purpose**: Learning path for developing agent harness for anthropics certification path
This is just my private hobby project to learn dealing with agentic loops, custom tool usages etc. 

## Usage

1. create an api key on anthropics platform. Store it in you password manager of your choice. In my case i am using the command line tool `pass`
   to read it directly from my encrypted vault from the script.
2. add `chmod +x` to the shell script harny
3. add ./harny to see what's happen

## Note

Currently the feature set is very limited on basic api call. During the path of my certification progress it will be enhanced with more features
